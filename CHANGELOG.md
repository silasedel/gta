# Changelog

Versions are MAJOR.MINOR.PATCH: MAJOR = huge overhauls, MINOR = sizable changes, PATCH = small fixes.

## v1.0.0 (Nov 13, 2026)
The first public version.
- **City and vehicles:** real-scale Miami from OpenStreetMap, original cars, and enterable boats.
- **Water:** swimming and diving with a visible seabed.
- **Police:** a six-star wanted system, and police dispatched from stations.
- **Interiors:** walk-in stores and restaurants.
- **Map and UI:** a pause map with dimmed off-limits areas, and a loading screen with a percentage.
- **Look:** the main character wears a teal short-sleeve shirt.
