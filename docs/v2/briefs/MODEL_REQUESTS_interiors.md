# Model requests: shop interiors (r7)

Everything below is code-built today (it works, but a real model would look better up close). Sizes are real-world meters.
Free-for-games licenses only (CC0 / CC-BY / "free for any use"); no real brand logos (we paint our own labels).
Put downloads in `Models/<Category>/` like the rest; the interiors agent converts them with `tools/v2/street-models/convert.py`
into `src/world/interiors/models/` (the pistols and the shopping cart are already done that way).
