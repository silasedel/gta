# Dad's brief: story missions and a casino heist (new files only; works alongside the others)

You build the **mission framework, about 6 story missions, and one casino heist** for Southline, an original GTA-style open-world game (three.js, Rapier). Make it feel like GTA V's missions: a marker to start, short cutscene-style dialogue, clear objectives with a GPS line, checkpoints, a "Mission Passed" screen with a payout, retry on fail. You work only in a **new folder `src/story/`**: do not edit any other file in the project except to add a line to `docs/v2/briefs/REQUESTS.md` if you need something. Other people are changing the rest of the game at the same time, so this keeps merging trivial.

## First steps
1. `npm install`, then `npm run dev` (opens at http://127.0.0.1:5200). In the game: Settings has a dev mode (enter the code `6969`) that helps you move around and test.
2. Read `READ_ME_FIRST.md` (mission, permissions, leave ~5% unused, tell the user which model and effort to use as the work changes), `src/jobs/jobs.v2.js` and `src/jobs/kit.js` (the best example: markers, panels, help text, kit-dressed peds that fight, enemy gunfire) and `src/gameplay/activities.js` (GPS routes, taxi, bounty). Copy their style.
3. Modules auto-load: create `src/story/story.v2.js` exporting `initV2(game)` and `export const order = 140;`. Use `game.on` / `game.emit` for events. Wanted level: `game.wanted` and the event `wantedChange` (`src/gameplay/wantedCore.js` explains the state machine). HUD helpers: `game.hud.notify`, `game.hud.help`, `game.hud.setMission`. Markers: `makeMarker` in `src/jobs/kit.js`. Money: `game.economy`. Persistence: follow how `game.jobs` saves its stats in the `jobs` save slice.

## What to build
1. **Framework (`src/story/`):** missions as data plus small scripts: `{ id, title, giver, start, stages: [{ goal, check, onEnter, onFail }], reward, retry }`. A mission board or phone entry (look at how jobs appear) plus world start markers. Mission Passed and Mission Failed overlays, restart from last checkpoint. Only one mission active at a time. Add `game.story = { list, active, start(id), cancel(), completed }` and a dev command `game.story.start('<id>')`.
2. **About 6 story missions** (5 to 12 minutes each), a simple connected story about Nico, a former smuggler in the Keys pulled into one last job. Use real systems: drive a vehicle to a point, chase a car, tail someone without being seen, a gunfight with kit-dressed enemies, steal a specific car, escape the police at a chosen star level, a boat run. Short voice-less dialogue in subtitle boxes with 2 to 3 choices at key moments that change a line or the payout.
3. **The casino heist** (GTA V structure): two **prep missions** (3-5 minutes each: scout the casino and learn what draws security; steal a getaway vehicle or gear and hide it at the back loading dock, or choose to steal the casino's own van in the moment) and a **finale** (10-15 minutes). In the finale the player first **creates a distraction**, choosing one: rig a slot machine to pay a huge jackpot to a planted accomplice (a celebration pulls the pit boss and guards to the floor); win big at roulette yourself (a real gamble that can fail); or pull the fire alarm (loud, alarms rise faster). Then slip through the staff corridor, handle the security room (cameras), open the vault within a 60-90 second window (being seen raises the alarm and the wanted level), fill the heavy duffel, leave by the loading dock, take the getaway vehicle and escape the chase. Outcomes: success pays more for a clean job; caught or killed means arrest or death and a retry.
   - There is **no casino interior yet** (the lead is building one). Build your own self-contained **heist set** inside your module: a simple casino floor, staff corridor, security room, vault and dock built from boxes and the models in `Models/` (see `Models/Casino/`), placed in a hidden area of the map and entered by a fade-teleport from the casino building's door (the casino tower stands at about x 2183, z -370 on Miami Beach, facing Collins Ave). Keep the layout in one data file so it can later be swapped for the proper interior.
4. **Quality:** every mission must be playable start to finish, failable and retryable with no soft locks; test each in the running app and take a screenshot at each stage. Subtitles and prompts in clear short American English. Made-up names only.

## Rules
- Only add files under `src/story/` (and `docs/v2/briefs/STATUS_dad.md`). Do not change shared files; if you need an API that is missing, write what you need in `docs/v2/briefs/REQUESTS.md` and use a safe fallback.
- Pace your usage: use what you have been given, leave about 5% unused, stop and report when close.
- When done (or when out of usage) give back the `src/story/` folder, `STATUS_dad.md` (what works, how to start each mission, what is missing) and your best screenshots. The lead merges it.
