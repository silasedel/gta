# vehicles-core: handoff (paused Nov 13, about 17:50 MST)

## Session 2 (Nov 13, about 18:00-18:45 MST)

**Wired:** `vehicles.js` now builds every car with `carModel2.js` (new lofted bodies, model/* parts). `carModel.js` (v1) is kept but unused; `carModel2.js.wip` is stale and can be deleted. Fixes made before wiring: patcher `sx` option, broken fuel-door block removed, EV grille check, rear seats no longer poke through the deck lid, smoother tail lamps. Added design-system brand badges (front, rear, via `src/design` `getBrand` + `logoCanvas`) and model-name lettering. Per-car `dispose()` now runs on despawn (per-car paint and plate textures were leaking).

**Unique cars:** `catalog.rollLook(key, seed, env)` / `lookSignature` / `visualSignature` / `legacyLook` / `fleetMix` / `tierWeight` / `incomeFor`. A look rolls paint (palette with color jitter, finish, two-tone, fade, patch panel), wheel style/rim/finish, ride height (applied to the shell), tint, dirt level and kind by zone (sand, salt, mud, soot), rust, dents (real vertex dents), missing hubcaps, stickers, accessories (racks, roof box, kayak, surfboard, ladder, bed box, light bar, bull bar, hitch, wing), cabin trim, dash clutter, plate number and design. A live registry re-rolls any look whose visual signature matches a live car. Model year (era) and tier per model. `game.vehicles.lookAudit(500)` -> `docs/v2/shots/vehicles-core/look_audit.json`: 500 built, 0 errors, 0 duplicate full or visual signatures, 50 models.

**Drivers:** `traffic/drivers.js` (8 types plus per-driver jitter, zone-biased mix). `aiDrive` uses them for speed, standstill gap and time headway, reaction lag (perceived gap), phone glances with weaving, braking/throttle style, amber/red behavior, stop signs (full stop or rolling) from `edge.src.controlA/B`, lane changes with blinkers and a gap check, horn, pedestrian margin, sirens (curb lane, crawl), wandering for lost drivers and tourists. Mapped signals had no phase source in the Miami city (`city.signalAt` / `trafficLight` missing), so traffic ignored lights before; `roadnet.signalState` now uses `game.traffic.signalAt` if present, else a fixed-time two-phase plan per signal node. **The signal heads drawn by the world do not follow this plan yet** (lead: whoever renders signals should read `fixedSignal` from roadnet.js, or provide `game.traffic.signalAt`).

**Measurement** (`docs/v2/shots/vehicles-core/personality_measurement.json`, 80 s, about 32 AI cars, Biscayne Blvd; the scripts are in the session scratchpad, not in the repo): speed vs limit 0.70 lost, 0.73 elderly, 0.79 tourist, 0.85 careful, 0.90 distracted, 0.93 show-off, 0.96 aggressive, 1.04 hurry; mean gap 9.9 m aggressive vs 16.5/16.7 m careful/elderly; lane changes per km 0 careful, 1.5 aggressive, 3.0 hurry; red lights 67 approaches, 2 run; stop signs rolled 4/4 aggressive, 5/6 hurry, 0/1 careful. Samples per type are small (1-6 cars).
